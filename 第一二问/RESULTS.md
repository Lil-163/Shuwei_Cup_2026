# 第一、二问真实数据运行结果

本次运行使用 `第一二问/run_analysis.py`，数据目录取自题目附带的 `Restocking_Problem_and_Data_EN`。训练、验证、测试按附件 `record_split.csv` 的环境划分；没有加入外部或人工生成的数据。输出由项目 `.venv` 中的 Python 环境生成。

## 数据检查

共读取 138 条序列、132,140 帧。按官方环境划分：训练 16 个环境（110 条序列，94,092 帧），验证 4 个环境（14 条序列，13,566 帧），测试 4 个环境（14 条序列，24,482 帧）。

## 问题一：观测质量分类

合格帧在验证集和测试集分别占 98.13% 和 98.11%。测试集结果：平衡准确率 0.567、坏帧召回率 0.530、坏帧精确率 0.025。多数类基线准确率为 0.981。

因此当前逻辑回归能找出一部分坏帧，但误报偏多，整体分类效果弱于只预测多数类的原始准确率基线。类别不平衡使普通准确率不适合单独评价；结果中保留坏帧精确率/召回率、平衡准确率供复核。不能据此声称质量识别已经可靠。
